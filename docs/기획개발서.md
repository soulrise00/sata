# 미래학 체험관 — 기획·개발서 (v1.0)

> “사주처럼 전 세계 미래학을 체험”하되, 결과가 **효용 있고 사실에 근거하며 삶에 도움**이 되도록 설계한 플랫폼의 기획·아키텍처·엔진·검증·배포 문서. 웹 에디션: `docs/plan.html`.

## 1. 배경과 목표
기존 운세 서비스는 ① 근거를 과장하거나 ② 모호하다. 이 플랫폼은 **제3의 길** — 전통을 존중하되 근거등급으로 투명하게 밝히고, 결과를 삶에 적용 가능한 질문으로 바꾼다.
- **체험성**: 아이콘을 누르면 실제 계산으로 결과(재현 가능한 명식·괘·차트).
- **사실 기반**: H·R·P·C·X 다섯 근거등급을 모든 결과에 표시.
- **효용성**: 결과를 ‘대상·사건·기간·조건·확률·반증’ 6칸으로 연결 → 스스로 채점 가능.

## 2. 가치 제안 (“5천원 이상”)
정확한 산출(만세력급 사주·64괘·실제 태양황경 별자리) + 구조 해설(오행·십신·강약·조후·체용·시나리오) + 정직한 한계(근거등급) + 삶의 적용(6칸·작은 시험·사후채점).

## 3. 체계 선정
원전 41개 전통 + 현대 검증예측 전체를 ‘도감’으로 수록, 계산 가능한 **11개를 대화형**으로 구현.
- 동아시아: 사주명리·주역·매화역수·띠
- 서양·근동: 서양 점성·타로·룬·르노르망·수비학
- 현대·검증: 생체리듬(참고)·현대 미래예측(포사이트)

## 4. 정보구조·UX
허브(히어로→근거등급 인포그래픽→권역별 아이콘 그리드→41 도감→매니페스토) · 체험 모달(소개+배지→입력 폼→결과 카드) · 결과 카드(요약→산출 비주얼→구조 해설→삶에 적용 6칸→주의 고지→다시/복사). 딥링크 `#saju`, 라이트/다크, 모바일 1열.

## 5. 기술 아키텍처
**정적 웹앱(무백엔드)**, 바닐라 JS, 빌드 불필요. 모든 계산이 클라이언트에서만 수행되어 **개인정보 비전송**. 외부 의존성은 Google Fonts뿐.

## 6. 계산 엔진 명세 (핵심)
- **사주**: Meeus 태양황경(±0.01°)으로 절기 경계 → 연주(입춘 보정)·월주(오호둔)·일주(`(JDN−11) mod 60`)·시주(오서둔). 지장간 가중 오행, 십신, 월령 가중 강약, 조후, 억부 용신, 대운.
- **주역·카드**: 동전 원시결과 기록 + `mulberry32` 시드 PRNG(시드 표기) → “다시 뽑지 않기”를 기술로 보장.
- **포사이트**: 기준율→오즈→우도비(약1.5·중2.3·강3.5) 곱셈 갱신→확률. 통제가능성·신호수로 범위 폭 조절 + Dator 4대 미래 + 사후채점.

## 7. 검증 결과 (Node 자동검증)
- 일주 앵커 **1900-01-01 = 甲戌**, 2000-01-01 = 戊午 (공인 역법 일치)
- 십신표 10×10 전체 원전과 완전 일치
- 입춘 경계 1984-02-05 = **甲子년 丙寅월**
- 주역 下巽/上坎 → **水風井 48괘**(원전 예제 일치), 64괘 역룩업 무결
- 별자리 1995-08-10 → **사자자리**, 카드 시드 재현성 통과
- UI: 11개 체험 전수 실행, 콘솔 오류 0, 모바일 가로 스크롤 없음
