미래학 체험관 기획·개발서

1. 배경과 목표

사람들은 사주·타로·별자리를 찾습니다. 재미 때문만이 아니라, 자기 삶의 질문을 정리할 언어가 필요하기 때문입니다.

기존 운세 서비스의 문제는 둘입니다. ① 근거를 과장해 “정해진 운명”처럼 말하거나, ② 반대로 아무 내용 없이 모호합니다. 이 플랫폼의 목표는 세 번째 길입니다. 전통을 문화유산으로 존중하면서, 각 체계가 무엇을 보장하고 무엇은 보장하지 않는지를 근거등급으로 투명하게 밝히고, 결과를 삶에 적용 가능한 질문으로 바꿔 줍니다.

  • 체험성: 아이콘을 누르면 실제 계산으로 결과가 나온다(가짜 랜덤 문구가 아니라 재현 가능한 명식·괘·차트).
  • 사실 기반: H·R·P·C·X 다섯 근거등급을 모든 결과에 표시한다.
  • 효용성: 모든 결과가 ‘대상·사건·기간·조건·확률·반증’ 6칸으로 연결되어 스스로 채점 가능한 예측이 된다.

2. 가치 제안 — “5천원 이상의 가치”

단순 운세 한 줄이 아니라, 한 번의 체험에서 다음을 모두 제공합니다.

구성내용가치
정확한 산출만세력급 사주 명식, 64괘, 실제 태양황경 기반 별자리 등재현 가능한 ‘진짜 계산’
구조 해설오행 분포·십신·강약·조후, 괘의 체용·변괘, 시나리오 분기나를 보는 구조적 언어
정직한 한계근거등급·주의 고지로 과신을 막음잘못된 결정 예방
삶의 적용6칸 질문 + 되돌릴 수 있는 작은 시험 + 사후채점실제 행동으로 연결

3. 체계 선정

원전 《미래예측 세계 대백과》의 41개 전통 + 현대 검증예측 전체를 ‘도감’으로 싣되, 실제 계산이 가능하고 개인이 바로 체험할 가치가 큰 11개를 대화형으로 구현했습니다.

권역대화형 체험(11)
동아시아사주명리 · 주역 · 매화역수 · 띠(십이지)
서양·근동서양 점성술 · 타로 · 룬 · 르노르망 · 수비학
현대·검증생체리듬(참고) · 현대 미래예측(포사이트)

자미두수·기문둔갑·조티샤 등 음력·정밀 천문 데이터가 필요한 체계는 도감으로 수록하고, 향후 데이터 확보 시 대화형으로 확장합니다(로드맵 참조).

4. 정보구조·UX

  • 허브(랜딩): 히어로 → 근거등급 인포그래픽 → 권역별 체험 아이콘 그리드 → 41개 도감 → 정직성 매니페스토.
  • 체험 패널(모달): 체계 소개 + 근거등급 배지 → 입력 폼(생년월일·질문 등) → ‘체험하기’ → 결과 카드.
  • 결과 카드: 핵심 요약 → 산출 비주얼(명식표/괘/막대/카드) → 구조 해설 → 삶에 적용(6칸) → 주의 고지 → 다시/요약복사.
  • 딥링크: #saju 등 해시로 특정 체험을 바로 열 수 있음.
  • 테마: 라이트/다크 자동 + 토글(기억). 모바일 1열 반응형, 가로 스크롤 없음.

디자인 언어: 밤하늘 남색 바탕 · 호박색(별·동양) 강조 · 청록(현대·과학) 보조 · 오행 5색. 제목 Noto Serif KR, 본문 Noto Sans KR, 데이터 모노.

5. 기술 아키텍처

정적 웹앱(무백엔드). 빌드 단계 없이 브라우저에서 바로 동작하는 바닐라 JS. 모든 계산이 클라이언트에서만 수행되어 생년월일·질문 등 개인정보가 서버로 전송되지 않습니다.

6. 계산 엔진 명세 (핵심)

사주 — 만세력급 계산

  • 태양황경: Meeus 저정밀식(오차 ~0.01°)으로 절기 경계를 판정. 입춘(황경 315°)에서 寅월이 시작, 30°마다 다음 월지.
  • 연주: 입춘 경계 보정 후 (연−4) mod 60. 월주: 월지=절기 섹터, 월간=오호둔(五虎遁).
  • 일주: 율리우스일 JDN 기준 (JDN−11) mod 60 (0=甲子). 시주: 시지=2시간 구간, 시간=오서둔(五鼠遁). 야자시 옵션 제공.
  • 파생: 지장간(본기·중기·여기) 가중 오행 분포, 일간 기준 십신, 월령 가중 강약(왕쇠), 조후, 억부 용신 후보, 대운 순·역·시작나이(3일=1년 근사).

주역·카드 — 재현 가능한 무작위

동전점은 원시 결과(앞/뒤)를 기록하고, 카드는 mulberry32 시드 PRNG로 뽑아 시드를 결과에 표기합니다. “유리한 결과가 나올 때까지 다시 뽑지 않기”라는 원전 원칙을 기술로 보장합니다.

현대 포사이트 — 베이즈 갱신

기준율을 오즈로 변환 → 신호(약/중/강 = 우도비 1.5/2.3/3.5)로 곱셈 갱신 → 확률로 환산. 통제 가능성·신호 수에 따라 범위 폭을 조절하고, Dator의 4대 미래와 사후채점 설계를 함께 출력합니다.

7. 검증 결과

엔진은 Node 환경에서 자동 검증했습니다(샘플).

  • 일주 앵커: 1900-01-01 = 甲戌, 2000-01-01 = 戊午 — 공인 역법과 일치.
  • 십신표: 일간 10×대상 10 전체가 원전 표와 완전 일치.
  • 입춘 경계: 1984-02-03=癸亥년, 02-05=甲子년 丙寅월 — 절기 경계 정확.
  • 주역: 下巽/上坎 → 水風井 48괘(원전 예제와 일치). 64괘 역룩업 무결.
  • 별자리: 1995-08-10(황경 137°) → 사자자리. 카드 시드 재현성 통과.

8. 결과 설계 원칙

  1. 계산된 실제 값에 근거: 모든 서술은 산출된 명식·괘·차트의 구체 값에서 나온다. 막연한 운세 금지.
  2. 상징과 현실의 분리: 상징 해석은 질문을 새로 보게 하는 힘으로, 현실 판단은 기준율·자료로.
  3. 조건부 서술: “~하면 ~ 경향” 형태. 숙명·단정 금지.
  4. 행동으로 연결: 6칸 + 되돌릴 수 있는 작은 시험 + 확인 날짜.

9. 개인정보·윤리

  • 비전송: 생년월일·질문은 브라우저에서만 처리되며 서버·제3자로 전송되지 않는다(무백엔드).
  • 저장 최소화: localStorage는 테마 설정 등 편의 값만. 체험 결과는 저장하지 않는다.
  • 안전 고지: 건강·법률·투자·생명 위험은 전통 해석 단독 근거 금지 문구를 결과마다 노출.
  • 차별 방지: 성별·직업·외모 고정관념을 상징으로 정당화하지 않는다.

10. 배포·운영

GitHub Pages로 정적 배포합니다. 저장소에 포함된 .github/workflows/pages.yml이 기본 브랜치 푸시 시 사이트를 게시합니다(저장소 설정에서 Pages 소스를 ‘GitHub Actions’로 지정). 단일 페이지 + 정적 자산이라 CDN 캐싱에 적합하고 서버 비용이 없습니다.
